コミュ読み君 使い方

シャニマスのコミュで、ボイスのない台詞（プロデューサーやスタッフなど）を読み上げて、読み終わったら次の台詞へ自動で進める Chrome の拡張機能です。非公式のファンメイドツールです。

1. はじめに用意するもの

  • パソコンの Google Chrome（Windows で確かめています。Mac はまだ確かめていません）
  • VOICEVOX（無料の読み上げソフト）
    1. https://voicevox.hiroshiba.jp/ からダウンロードしてインストールします
    2. 一度起動して、利用規約に同意しておきます

2. 拡張機能を入れる

  1. Chrome で Chrome ウェブストアのコミュ読み君のページ（リンクは準備中です） を開きます
  2. 「Chrome に追加」を押します
  3. ツールバーのパズルのマークから「コミュ読み君」をピン留めしておくと、すぐ開けて便利です

入れる時に「shinycolors.enza.fun」と「127.0.0.1」のデータへのアクセスを求められます。ゲームの画面で台詞を読むためと、同じパソコンの VOICEVOX に読み上げを頼むためです。ゲームのサーバーや外のサーバーには何も送りません。

3. 使う

  1. VOICEVOX を起動しておきます（開いておくだけで大丈夫です）
  2. Chrome でシャニマスを開いて、コミュを再生します
  3. ボイスのない台詞が読み上げられ、ボイスと読み上げが終わると次の台詞へ自動で進みます
  4. 選択肢では止まって、声でお知らせします。選択肢は自分で選んでください

拡張機能のアイコンに「ON」と出ている間は動いています。「OFF」は一時停止中です。VOICEVOX を閉じると止まり、いつものゲームのままになります。

自分で操作してもかまいません

  • 台詞をタップして自分で進める、ログを開く、早送り・SKIP する、などをしても、拡張機能は待ってから続きを進めます
  • ログを開いている間は止まり、閉じると続きから読み上げます

別の窓で作業しながら

ゲームは本来、別の窓を触ると音が止まりますが、コミュを流している間は止めずに進めます。ゲームの画面が少しでも見えていれば、ほかの窓を操作していても止まりません。

Chrome を最小化した時、別のタブに切り替えた時、Chrome の窓がほかの窓で完全に隠れた時は、一時停止します。ゲームの画面に戻ると、自動で続きから再開します。

コミュ並列閲覧

ゲームの「コミュ並列閲覧」でも使えます。サブ画面のコミュだけを読み上げて進め、その間メイン画面の音は消します。メイン画面のコミュは読み上げません。

4. ポップアップ（拡張機能のアイコンを押すと出る画面）

項目内容
エンジン起動中／未起動VOICEVOX が動いているか
状態動作中・コミュ待ち・選択肢を選んでください・一時停止中 など
一時停止／再開一時停止すると、読み上げと自動で進めるのを止めます（自分で台詞を進めて読めます）
有効外すと拡張機能が止まります
読み上げの速さ・音量読み上げの声の速さと大きさ
行と行の間台詞が終わってから次へ進むまでの間
改行の間台詞の中で改行がある時に入れる間
全文をすぐ表示次の台詞に進んだ時、文字を一度に全部出します
選択肢を声で知らせる選択肢で止まった時に声でお知らせします
声の設定区分（プロデューサー・男性・女性・子ども など）ごとの声を、試聴して選べます。話者ごとに区分を直すこともできます

一時停止／再開は Ctrl+Shift+1 でもできます（Chrome の外を操作中でも効きます）。他のアプリと同じキーで効かない時は、chrome://extensions/shortcuts で変えられます。

5. 困った時

こんな時ためしてほしいこと
読み上げない・進まないVOICEVOX が起動しているか、ポップアップの「エンジン起動中」と「有効」を見てください
「一時停止中」で止まった（ポップアップに「次の行が始まりません」など）ポップアップの「再開」か Ctrl+Shift+1 を押してください。台詞が進んでいなければ、ゲームの台詞を1回タップしてから再開してください。次のコミュを再生した時は自動で動き出します
「ゲームの画面が隠れたので一時停止中」と出た最小化・別のタブ・ほかの窓で完全に隠れた時の一時停止です。ゲームの画面に戻ると自動で再開します
「今の行が分かりません」と出たゲームの台詞をタップして次の台詞へ進めると、そこから追います
コミュの最初の台詞だけ読み上げが遅れる読み上げの準備中です（そのまま待てば読み上げます）
声が合っていない（女性なのに男性の声など）「声の設定」の「これまでに出た話者」で区分を直せます
ショートカットが効かない他のアプリが同じキーを使っているかもしれません。chrome://extensions/shortcuts で変えてください
